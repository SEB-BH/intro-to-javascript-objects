### Prerequisites

- JavaScript Control Flow
- Intro to JavaScript Functions

### Teaching notes

- Start with the physical idea of a shopping cart: the cart groups named details; its `items` array holds an ordered list.
- Code along in `app.js`. Ask learners to predict each `console.log` before running `node app.js`.
- Each section's full `const cart = ...` example replaces the previous declaration. In the optional lessons, examples are standalone unless stated otherwise.
- Keep the six core sections first. Introduce the Level Up sections after students can read `cart.items[0].name` and explain each step.
