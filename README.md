## About

This module introduces JavaScript objects through one shopping cart. Students first label the parts of an object, then create and change cart properties, write methods, and put product objects inside an array. Each core lesson includes a short exercise and examples that can be run in `app.js` with Node.js. Optional lessons explore additional object features after the fundamentals.
